PROJECT 01 / ENGINEERING NOTES

Inside Logic Lens.

A code review workspace that brings the explanation closer to the code.

01 / THE EXPERIENCE

More than a final answer.

The workspace supports bug analysis, progressive DSA hints, time and space complexity explanations, and corrected-code diffs. React connects to FastAPI for streamed responses, authentication, and saved review history.

02 / THE RETRIEVAL PATH

Give the model useful context.

The optional RAG feature accepts PDF, Markdown, and text documents. It chunks and embeds their content, stores vectors in PostgreSQL with pgvector, retrieves relevant chunks, and adds them to the review prompt. Source references accompany the result.

RAG is an optional implementation in the source repository. Its availability depends on the deployment configuration.

03 / THE BACKEND DETAILS

Make the workflow dependable.

JWT-protected endpoints, per-user history, response caching, request rate limits, and structured API errors support the review workflow. Streaming improves how feedback arrives; it does not eliminate model latency.

PROJECT 02 / IN DEVELOPMENT

Inside CommuteCircle.

A familiar route can become a shared ride. The experience should respect the people using it.

01 / THE IDEA

Start with the commute.

Drivers list a journey they are already making. Other commuters discover rides with compatible origins, destinations, departure times, and seat availability.

02 / CURRENT WORK

Build the core experience first.

The project is being developed with React Native (Expo), Python, FastAPI, and PostgreSQL. Current work centers on the app foundation and ride-listing flow.

03 / PRIVACY BY DESIGN

Meet nearby, without sharing everything.

The matching concept uses public pickup points and walking-distance and detour limits, so sharing a ride need not require disclosing a home address. This matching feature is in development.

The map and phone shown on this portfolio are concept illustrations. They are not a live service or a production app screenshot.
