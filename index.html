02 / THE RETRIEVAL PATH

Give the model useful context.

Documents→Embeddings→pgvector→Prompt + LLM

The optional RAG feature accepts PDF, Markdown, and text documents. It chunks and embeds their content, stores vectors in PostgreSQL with pgvector, retrieves relevant chunks, and adds them to the review prompt. Source references accompany the result.

RAG is an optional implementation in the source repository. Its availability depends on the deployment configuration.

JWT-protected endpoints, per-user history, response caching, request rate limits, and structured API errors support the review workflow. Streaming improves how feedback arrives; it does not eliminate model latency.

LOGIC LENS / GUIDED SAMPLE

From code to clarity.

Follow a two-sum example from its first implementation to a clearer, faster approach.

def two_sum(nums, target):
    for i in range(len(nums)):
        for j in range(i + 1, len(nums)):
            if nums[i] + nums[j] == target:
                return [i, j]
    return []

START WITH A WORKING IDEA

Correct answers.
Too many comparisons.

The task: find two distinct indices whose values add up to the target. This implementation checks pairs until it finds a match.

[2, 7, 11, 15] → target 9

The answer is indices [0, 1]. What happens as the input gets larger?

EXAMPLE REVIEW

Understand the trade-off.

Each value scans the values after it. In the worst case, the number of checks grows quadratically.

  • Remember values already seen in a lookup map.
  • For each value, look for target − value.
  • Check before inserting to avoid reusing the same index.
A hint before the solution

If the current value is 7 and the target is 9, have you already seen a 2?

Current worst-case timeO(n²)Hash-map expected timeO(n)

The improvement uses O(n) extra space. Expected linear time assumes average constant-time map operations.

def two_sum(nums, target):
    seen = {}
    for i, value in enumerate(nums):
        complement = target - value
        if complement in seen:
            return [seen[complement], i]
        seen[value] = i
    return []
